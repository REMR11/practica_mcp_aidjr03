# MCP Resources

| URI                             | MIME type          | Description              |
| ------------------------------- | ------------------ | ------------------------ |
| `api://documentation/overview`  | `application/json` | General API metadata     |
| `api://documentation/endpoints` | `application/json` | Full endpoint catalog    |
| `api://documentation/schemas`   | `application/json` | Component schema catalog |

Resources reflect the currently loaded OpenAPI document configured through environment variables.
